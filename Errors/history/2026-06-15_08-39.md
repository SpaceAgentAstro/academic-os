## Risk Analysis

- **Auth is opt-in by env (`API_KEY`).** When unset the API stays open (local dev)
  and logs a warning; production deployments MUST set it and bind behind a proxy.
  This keeps local development frictionless without weakening a configured deploy.
- **Attempt dedup deletes the prior attempt** for a `(session, question)` pair. This
  is intentional (re-marking replaces), but means historical re-marks are not kept;
  acceptable per the "one attempt per question per session" contract.
- **Grade-scale change (LOGIC-003)** means some previously "A" recent-paper grades
  now read "B" — this is the corrected Edexcel boundary behaviour, not a regression.
- **Predicted-grade formula change (LOGIC-013)** lowers some optimistic predictions
  by design.
- **CSP** is deliberately moderate (`'unsafe-inline'`/`'unsafe-eval'` for scripts) so
  Next.js' runtime keeps working; tightening to nonces is a future hardening step.
- **Security-headers / rate-limit middleware** add a small per-request cost; the
  rate limiter is in-process (per instance), adequate for single-instance deploys.
