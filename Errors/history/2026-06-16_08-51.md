## Risk Analysis

- **Auth middleware is opt-in via `API_KEY`.** Default (unset) preserves the
  existing local-dev behaviour and logs a warning, so no current workflow
  breaks; production must set `API_KEY` + `NEXT_PUBLIC_API_KEY`. Low regression
  risk, high security upside.
- **Attempt upsert changes write semantics** (delete-then-insert per
  session/question). Verified one row remains after re-marking and aggregations
  stay correct; only affects same-session re-marks.
- **`paper_totals` / `weak_topics` / removed `grade_contribution`** changed the
  dashboard/attempt payloads; frontend types updated in lockstep, `tsc` clean.
- **Streak now counts completed sessions only** — values may legitimately drop
  for users who previously inflated via opened-but-abandoned papers (intended).
- **OCR refactor** preserves outputs; all ingestion tests pass with deps present.
- **Rate limiter is in-process** (per-instance); adequate for single-instance
  deploys, would need shared state behind a multi-instance LB (noted).
