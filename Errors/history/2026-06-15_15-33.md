## Risk Analysis

- **API-key auth is opt-in.** When `API_KEY` is unset the API stays open (logged
  as a WARNING) to preserve local dev; set it before any public deployment. The
  frontend forwards it via `NEXT_PUBLIC_API_KEY` (visible to clients — acceptable
  for this single-user threat model, not a per-user secret).
- **Attempt de-dup** changes write semantics: re-marking now replaces the prior
  attempt and its mistakes for a `(session, question)`. Standalone attempts
  (`session_id` null) are unaffected. Per-session aggregates can no longer exceed
  the paper total.
- **Predicted-grade** numbers shift downward slightly vs the old flat +10 — this
  is the intended correction (the old value overstated readiness).
- **Hash routing** changes URLs to `#/route`; existing bookmarks to `/` still land
  on Home. No server routes changed.
- **CSP** permits `'unsafe-inline'` styles/scripts (Next emits inline) and the
  pinned jsDelivr CDN; tighten to nonces once inline usage is removed.
