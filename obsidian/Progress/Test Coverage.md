## Testing Policy

- **In-memory SQLite** for all DB tests — never mock databases
  - Reason: past incident where mocks passed but prod migration failed
- **Fixture PDFs** generated by fpdf2 — realistic but controlled content
- **Rollback strategy**: transaction → validate → commit or rollback (in get_db context manager)
- **No pix2tex in tests** — optional dependency, gracefully absent

## Running Tests

```bash
cd academic-os
PYTHONPATH=. .venv/bin/pytest tests/ -q
```

Or with coverage:
```bash
PYTHONPATH=. .venv/bin/pytest tests/ --cov=. --cov-report=term-missing
```
